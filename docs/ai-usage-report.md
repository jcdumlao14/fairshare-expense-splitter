# AI Usage Report

## Project

FairShare — AI-Assisted Expense Splitter

## Homework

Homework 2 — Build and Ship an AI-Assisted Full-Stack App

## AI Tool

ChatGPT

## Purpose

AI assistance is being used to accelerate software development while maintaining developer review and verification.

## Phase 1 Usage

### Product Planning

AI was used to help define:

- Product scope
- Target users
- User stories
- Acceptance criteria
- Functional requirements
- Non-functional requirements
- Non-goals
- Success criteria

### Project Structure

AI was used to propose:

- Backend/frontend separation
- Documentation structure
- Testing structure
- OpenAPI contract location
- AI development instructions

### Development Guidelines

AI was used to draft initial development guidelines for `AGENTS.md`.

## Human Verification

All AI-generated project specifications and development instructions are reviewed by the developer before being committed.

The developer remains responsible for:

- Requirements
- Architecture decisions
- Code review
- Testing
- Correctness
- Security
- Final commits

## AI-Assisted Development Principle

AI-generated code will not be accepted without review.

The development process will use the following cycle:

1. Ask AI for a plan.
2. Review the proposed plan.
3. Generate or modify code.
4. Inspect the changes.
5. Run tests.
6. Verify behavior.
7. Commit only verified changes.
